
# 💼 Software Developer Salary Prediction App

An interactive web application built with **Streamlit** that predicts the salary of software developers based on their **country**, **education level**, and **years of professional experience**. The app leverages a machine learning model trained on real-world developer survey data.

---

## 🚀 Project Overview

This project showcases end-to-end data science capabilities, including:
- Data preprocessing
- Feature encoding
- Model training (Random Forest Regressor)
- Web app development using Streamlit
- Deployment-ready interface for salary prediction

---

## 🧠 Machine Learning Model

- **Algorithm**: Random Forest Regressor  
- **Encoding**: Label Encoding for categorical inputs (country, education)  
- **Model File**: Serialized using `pickle`  
- **Input Features**:  
  - Country  
  - Education Level  
  - Years of Experience
